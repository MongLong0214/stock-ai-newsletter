# Stock Prepare: 2026-10-12 개선 후보

## 결론과 PR 범위

별도 HGB 회귀 모델로 `touch10`과 `비용 차감 후 D5 비손실`을 학습하고,
`clip(touch) × clip(nonLoss)²`를 종합점수의 원값으로 사용한다.
이번 탐색 중 급등 도달률과 손실률의 조합이 가장 나은 후보다. **운영 성능 검증 완료는 아니다.**
117일 비교의 손실률은 여전히 53.7%, 평균 순수익은 −0.23%, 추천일 양봉률은 42.0%다.
손실률 약 30%와 높은 추천일 양봉률 목표를 달성하지 못했다. 초안 PR로 검토하며 main 병합·운영 발송은 수행하지 않는다.
이 브랜치를 병합하면 Prepare가 새 동결 모델을 사용하므로 단순 연구 문서 PR로 오해하면 안 된다.

종합 정수점수 내림차순 → 20일 평균 거래대금 내림차순 → ASCII ticker,
3종목, 기존 공통 게이트, 20거래일 재추천 제외를 유지한다.
당일 백분위나 점수 하한을 넣지 않는다. 학습 날짜를 동일 가중한 기준 분포에서 평균 50·+1σ 70인 기존 환산식을 유지한다.
UI, 이메일 템플릿, 제품 문구, Analysis Summary는 변경하지 않는다. 6개 기술 점수 계산과 변동성의 기존 기준값도 유지한다.

## 실제 발행본 감사

2026-10-12 오전 10시 시점의 10/2·6·7·8 발행 12건은 추천일 양봉 5/12(41.7%),
현재 시가 대비 손실 10/12(83.3%), 평균 수익률 −6.81%(비용 전), 장중 +10% 도달 4/12(33.3%)였다.
새 로직의 완결된 5거래일 결과는 이 감사 시점에 0건이므로 현재 손실률을 최종 D5 손실률로 표시하지 않는다.
아이씨티케이는 +21.64% 터치 뒤 −8.62%, 성호전자는 +13.34% 터치 뒤 −1.26%였다.
따라서 **+10% 장중 터치와 최종 수익은 다른 결과**다. 최고가 터치를 실제 체결 이익으로 계산하지 않는다.
발행본 15건과 snapshot의 종목·점수·신호 종가는 일치했고, KIS 확정 OHLCV/저장시세와 달력 대조 차이는 0건이었다.

기존 목표 `(.8*T10 + .2*D1bull + .65*(1-L0))/1.65`는 급등 터치가 손실을 상쇄할 수 있다.
또 −1%와 −20%를 동일한 손실로 처리한다. 이번 후보는 손실 크기를 직접 예측하지는 않지만,
터치와 비손실을 분리해 낮은 비손실 예측이 높은 터치 예측에 묻히지 않게 한다.
숫자만 재환산해서 타율이 개선됐다고 주장하지 않는다.

## 재현

원시 시세·feature corpus·npz·joblib·일별 원장·로그는 Git에 넣지 않는다.
로컬 입력 `prices.ndjson`은 `[symbol, StockDailyPriceRow[]]`, `master.json`은 현재 master 배열,
`calendar.json`은 `{tradingDays: 날짜오름차순배열}`이다. 먼저 원천·날짜·페이지 누락을 확인한 읽기 전용 추출본을 준비한다.
아래 경로 변수는 각자 추출본과 결과 저장 위치를 가리킨다.

```sh
npx tsx scripts/stock-picks/export-utility-research.ts --prices "$SNAPSHOT/prices.ndjson" --master "$SNAPSHOT/master.json" --calendar "$SNAPSHOT/calendar.json" --from 2025-03-04 --output-dir "$EXPORT"
uv run --script scripts/stock-picks/benchmark-composite-utility.py --features "$EXPORT/features.ndjson" --calendar "$EXPORT/calendar.json" --output "$RESULTS/comparison.json"
uv run --script scripts/stock-picks/train-composite-utility.py --features "$EXPORT/features.ndjson" --feature-spec "$EXPORT/feature-spec.json" --calendar "$EXPORT/calendar.json" --prices "$SNAPSHOT/prices.ndjson" --as-of 2026-10-08 --target touch-nonloss-v1 --output "$RESULTS/model.json" --audit-dir "$RESULTS/fit"
```

재현 benchmark는 최초 비교와 요약 수치가 모두 일치했다.
학습 audit은 실제 관측 2,048건·전체결측·0·개별결측·1,200개 분기의 equality/adjacent 경계를 포함해 5,700건을 검증했다.
두 native head와 portable head 차이는 0, 결합값 최대 수치오차 1.39e−17, 정수점수 차이 0이었다.
실제 TypeScript와 native 결합값/정수점수 5,700건 대조 차이는 각각 0이었다.
기존 KIS raw320→50입력 witness의 입력은 유지하고 새 sklearn 모델로 기대 예측값만 갱신했다.
