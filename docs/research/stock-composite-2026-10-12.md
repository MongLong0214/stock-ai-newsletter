# Stock Prepare: 2026-10-12 추천 로직 개선

## 결론과 PR 범위

별도 HGB 회귀 모델로 `touch10`과 `비용 차감 후 D5 비손실`을 학습하고,
`clip(touch) × clip(nonLoss)²`를 종합점수의 원값으로 사용한다.
이번 탐색 중 급등 도달률과 손실률의 조합이 가장 나은 후보다. **운영 성능 검증 완료는 아니다.**

손실률 약 30%와 높은 추천일 양봉률 목표를 달성하지 못했다.

이 변경은 실제 Prepare의 동결 모델을 교체한다. 코드 검증 통과가 예측 성능 목표 달성을 의미하지 않는다.

종합 정수점수 내림차순 → 20일 평균 거래대금 내림차순 → ASCII ticker,
3종목, 기존 공통 게이트, 20거래일 재추천 제외를 유지한다.
당일 백분위나 점수 하한을 넣지 않는다. 학습 날짜를 동일 가중한 기준 분포에서 평균 50·+1σ 70인 기존 환산식을 유지한다.
UI, 이메일 템플릿, 제품 문구, Analysis Summary는 변경하지 않는다. 6개 기술 점수 계산과 변동성의 기존 기준값도 유지한다.

## 실제 발행본 감사

2026-10-12 오전 10시 시점의 10/2·6·7·8 발행 12건은 추천일 양봉 5/12(41.7%),

따라서 **+10% 장중 터치와 최종 수익은 다른 결과**다. 최고가 터치를 실제 체결 이익으로 계산하지 않는다.

기존 목표 `(.8*T10 + .2*D1bull + .65*(1-L0))/1.65`는 급등 터치가 손실을 상쇄할 수 있다.
또 −1%와 −20%를 동일한 손실로 처리한다. 이번 후보는 손실 크기를 직접 예측하지는 않지만,
터치와 비손실을 분리해 낮은 비손실 예측이 높은 터치 예측에 묻히지 않게 한다.

아래 경로 변수는 각자 추출본과 결과 저장 위치를 가리킨다.

```sh
npx tsx scripts/stock-picks/export-utility-research.ts --prices "$SNAPSHOT/prices.ndjson" --master "$SNAPSHOT/master.json" --calendar "$SNAPSHOT/calendar.json" --from 2025-03-04 --output-dir "$EXPORT"
uv run --script scripts/stock-picks/benchmark-composite-utility.py --features "$EXPORT/features.ndjson" --calendar "$EXPORT/calendar.json" --output "$RESULTS/comparison.json"
uv run --script scripts/stock-picks/train-composite-utility.py --features "$EXPORT/features.ndjson" --feature-spec "$EXPORT/feature-spec.json" --calendar "$EXPORT/calendar.json" --prices "$SNAPSHOT/prices.ndjson" --as-of 2026-10-08 --target touch-nonloss-v1 --output "$RESULTS/model.json" --audit-dir "$RESULTS/fit"
```

재현 benchmark는 최초 비교와 요약 수치가 모두 일치했다.
학습 audit은 실제 관측 2,048건·전체결측·0·개별결측·1,200개 분기의 equality/adjacent 경계를 포함해 5,700건을 검증했다.

실제 TypeScript와 native 결합값/정수점수 5,700건 대조 차이는 각각 0이었다.
기존 KIS raw320→50입력 witness의 입력은 유지하고 새 sklearn 모델로 기대 예측값만 갱신했다.

## 2026-10-16: 거래불가 진입과 보유 중 거래정지 (#228)

오케스트레이터가 운영 데이터를 읽기 전용으로 측정한 결과, 시장 전체 2024-08-28~2026-10-16에
O=H=L=C·거래량>0·종가≥전일 종가×1.29인 상한가 잠김 일봉은 306건이었다.
그중 신호일 상승률이 10% 미만인 다음 날 발생한 건은 160건이다.
실제 저장 snapshot 추천 210건(모든 전략·shadow 포함, 2026-09-03~10-08)의 D1 상한가 잠김과
D1 거래량 0은 각각 0건이었다. 이 수치는 오케스트레이터 제공 실측이며 이번 오프라인 변경에서 재측정하지 않았다.
위 1.29 탐지 건수는 정확한 호가 단위 계산을 적용한 연구 corpus 건수와 구분한다.

라벨러는 같은 PriceBook의 신호일 종가×1.30을 해당 가격대 호가 단위로 내림해 상한가를 계산한다.
양수 거래량이 있어도 D1 O=H=L=C가 이 가격 이상이면 `unexpected_untradeable`로 분류한다.
신호일 행이 없으면 기존 동작을 유지한다. 운영 선정 코드와 동결 모델은 변경하지 않는다.
export의 기존 학습 제외 조건을 유지하면서 `labelNullReason`을 추가했다:
`suspendedOrUntradeable`은 관측된 D1~D5 거래량 0 또는 거래불가 진입,
`immature`는 창 미완결, `dataError`는 그 외 데이터 오류다. 이미 관측된 거래정지·잠긴 진입은 미성숙보다 우선한다.
기존 로컬 파일 export 명령의 마지막 JSON은 연구 후보 행 기준 `lockedLimitUpEntries`, `suspensionPaths`,
`unknownReasons`를 출력한다. 두 경로 건수는 중복될 수 있으며, 원본 입력을 읽고 별도 출력 디렉터리만 쓴다.

benchmark는 기존 지표와 분모를 유지하고 `unknownReasons` 및 다음 보수 지표를 추가한다.
`lossRateConservative`는 (정상 라벨 손실 수+거래정지·거래불가 수)/(정상 라벨 수+거래정지·거래불가 수)다.
`meanNetConservative`는 같은 분모에 거래정지·거래불가 순수익을 해당 집계 구간의 최악 관측 순수익과
−0.3%(왕복 비용) 중 더 낮은 값으로 대입한다. 정상 관측이 없으면 전액 손실+비용인 −100.3%를 가정한다.
대입값은 `suspendedOrUntradeableNetAssumption`으로 출력한다. 미성숙과 기타 데이터 오류는 이 분모에서도 제외한다.
사유가 없는 과거 export의 완결 창 null 라벨은 `unclassified`로 남겨 거래정지나 미성숙으로 추정하지 않는다.
정상 관측이 없는 기존 조건부 지표는 null이다. 보수 수치는 민감도 가정이며 체결 결과가 아니다.
이번 변경에서는 corpus 재추출·재학습·benchmark 재실행을 하지 않았으므로 기존 성과표를 갱신하거나 새 보수 성과 수치를 주장하지 않는다.

## 2026-10-16: 거래비용 현실화 민감도 (#227)

기존 모델 비용 30bps 지표를 그대로 두고, 종목별 진입·청산 가격과 매도 거래일을 반영한
현실 비용 지표를 나란히 계산한다. 운영 선정, 동결 모델 artifact, 학습 라벨과
`utility_target.py`의 `nonLoss = D5close/entry-1-.003 >= 0` 정의는 변경하지 않는다.
현실 비용으로의 재학습 여부는 별도 PR에서 결정한다.

진입가 E는 D1 시가, 청산가 X는 D5 종가, D는 D5 매도 거래일이며, 모든 비용은 진입금액 대비다.
수수료 c(bps/side), 슬리피지 s(P)(bps/side), 매도세 t(D)(bps)에 대해:

```text
s(P) = slippageTicksPerSide × krxTickSize(P) / P × 10,000
cost = (c + s(E)) / 10,000 + (c + t(D) + s(X)) / 10,000 × (X / E)
net = X / E - 1 - cost
```

매도 수수료·세금·슬리피지는 청산금액에 부과하므로 X/E를 곱한다.
`costBps`와 반환되는 세금·수수료·슬리피지 구성 비용은 모두 진입금액 기준 bps다.
호가 단위는 2023-01-25 이후 KRX 통합표를 사용한다:
2천원 미만 1원, 5천원 미만 5원, 2만원 미만 10원, 5만원 미만 50원,
20만원 미만 100원, 50만원 미만 500원, 그 이상 1천원이다.

오케스트레이터가 확인한 세율·결제 사실을 구현하며 이번 오프라인 작업에서 다시 조회하지 않았다.
2026-01-02 결제분부터 KOSPI는 거래세 0.05%+농특세 0.15%, KOSDAQ은 거래세 0.20%로
합계가 모두 0.20%(20bps)다. 2025년은 양 시장 합계 0.15%(15bps), 2024년은 0.18%(18bps)다.
T+2 결제일 기준을 원천 시세의 KRX 거래일 달력으로 환산한 매도 거래일 경계는 다음과 같다.
2025-12-29 이후 20bps, 2024-12-27~2025-12-28은 15bps,
2023-12-27~2024-12-26은 18bps다. 2023-12-27 이전은 지원하지 않고 오류로 처리한다.
현재 데이터 시작일은 2024-08-28이다.

수수료 기본값은 일반적인 온라인 요율을 가정한 편도 1.5bps이며 **실제 계좌 요율은 미확인**이다.
슬리피지는 시가·종가 단일가 가격에서 편도 반 호가(0.5 tick)를 가정한다.
두 값 모두 비용 함수 인자로 바꿀 수 있다. 호가표는 라벨러의 상한가 계산과 공유한다.
이는 주문 크기·호가 잔량·충격 비용을 실측한 체결 결과가 아니다.

포워드 보고서의 D5 비용은 항상 실제 거래일 인덱스의 D5를 사용한다.
8보유일 참고 집계도 기존 `return5d`의 청산일은 D5로 유지한다.
D1 당일 청산 요약에는 D1 종가·D1 매도일을 쓴다.
목표가 청산 모형은 도달 시 +10% 가격, 미도달 시 D5 종가를 쓰되 도달일을 저장하지 않아
D5 세율을 가정한다. 목표가 체결이나 도달일의 정확한 세후 수익을 보장하지 않는다.

benchmark는 모든 기존 구간·정책별 지표를 유지하고 `lossRateRealisticCost`,
`meanNetRealisticCost`, `medianNetRealisticCost`, `severeLossRateRealisticCost`,
`meanAppliedCostBps`를 추가한다. 손실은 net<0, 큰 손실은 net≤−10%다.
거래정지·거래불가 보수 지표는 #228과 같은 분모를 쓰며, 현실 비용 순수익 중 구간 최악값과
−30bps 중 낮은 값으로 대입한다. 정상 관측이 없으면 기존 −100.3% 가정을 유지한다.
unknown의 정확한 진입·청산 가격을 알 수 없으므로 이 대입 비용까지 실측했다고 해석하지 않는다.
