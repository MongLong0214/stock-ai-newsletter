# Stock Prepare: 2026-11-02 종합점수 v8 투자자 수급 입력 추가

## 결론과 변경 범위

v8은 v7.1의 정렬 규칙 **`pred − 0.5 × poolStd(pred) × z(ATR14)`**과 점수 곡선을 그대로 유지한다.
바뀌는 것은 예측 모델 하나다. 기존 50개 관측 입력에 **KIS 종목별 투자자 매매동향(FHPTJ04160001) 15개 입력**을 더해
v6와 같은 수익 목표·HGB 설정으로 다시 학습했다(`composite-return-v8`).

사전 등록한 채택 기준(PREREG addendum 5)을 통과했고, 같은 비교 구간에서 v7.1(K2)보다 타율과 평균 순익이 모두 높았다.
**다만 v7.1 대비 차이는 통계적으로 유의하지 않다(타율 +1.58%p, p=0.18). 운영 성능 개선이 입증된 것은 아니다.**

UI, 이메일 템플릿, 제품 문구, Analysis Summary는 변경하지 않는다. 목표가·손절가는 표시하지 않는다.
공개 점수의 의미(학습 기준 평균 50·+1σ 70·완만한 상단 꼬리)는 v6·v7.1과 같다. 섀도우 전략은 변경하지 않는다.

## 수급 입력 (PREREG addendum 5, 2026-11-02 10:12 KST, 결과 확인 전 등록)

- 원천: KIS `FHPTJ04160001`(종목별 투자자매매동향 일별). 순매수 금액은 백만원 단위, 거래대금(`acml_tr_pbmn`)은 원 단위다.
- 시점: 신호일 t의 수급은 장 마감 후 확정된다. Prepare는 다음 날 아침 진입 시가 전에 실행하므로 t 시점 정보로 쓸 수 있다.
- 비율: 같은 창의 순매수 금액 합 × 1e6 / 거래대금 합. 창 안 하루라도 비면 결측이다.
- 15개 입력: 외국인 1·5·20일, 기관 1·5·20일, 개인 5·20일, 투신 5일, 연기금 5일, 사모 5일,
  외국인·기관 연속 순매수 일수(부호 포함, ±20 상한), 외국인·기관 5일 동시 순매수 여부, 외국인 5일 − 20일.

| 정책 | 정의 |
|---|---|
| F1 | v6 목표·설정, 50 + 15 입력 |
| **F2** | 당일 z(F1) − 0.5 × z(ATR14) (v7.1 K2와 같은 형태) |
| F3 | K2 + 수급 위험 플래그 워크포워드 veto(G2 규칙) |

채택 기준은 기존과 같다(전체 타율·EV > v6, H2 타율·EV ≥ v6, 14개월 중 8개월 이상 타율 ≥ v6).
운영 교체에는 추가로 **전체 타율과 EV 모두 K2(v7.1) 초과**를 요구했다. 결과 확인 후 파라미터는 바꾸지 않았다.

- F1이 EV는 가장 높지만, 제품 목표가 개별 종목 타율이고 큰 손실(L5)이 더 적은 F2를 운영안으로 골랐다.
  K2 대비 비교 통계는 결과 확인 후 계산한 기술 통계이며 채택 판정에 쓰지 않았다.

## 운영 구현

- `scripts/stock-picks/investor-flow.ts`: KIS 원천 행 파싱(`parseInvestorFlowRows`), 15개 입력 계산(`buildInvestorFlowInputs`),
  운영 조회(`loadInvestorFlowInputs`).
- Prepare는 신호일 기준으로 후보 풀(재추천 제외 전) 종목마다 KIS를 **1회** 호출한다. 한 번에 30거래일이 오므로 연구 입력과 같다.
  연속 일수는 ±20에서 자르므로 30거래일 창이면 전체 이력과 같다. DB 테이블은 추가하지 않았다.
- 호출: 동시 4건, 초당 8건 상한, 종목별 3회 재시도(지수 백오프). 토큰·오류 분류는 기존 KIS 시세 조회와 같다.
- **커버리지 게이트**: 풀 종목의 신호일 수급 행이 95% 미만이면 추천을 중단한다(백업 cron이 재시도). v7.1로 대체하지 않는다.
  개별 결측 종목은 모델의 결측 분기로 처리한다(연구 평가 구간 커버리지 99.5%).
- 전략 해시에 입력 버전(`observed-50-v1-2026-09-30+kis-investor-flow-15-v1-2026-11-02`), 수급 원천, 창 길이, 커버리지 기준을 포함한다.
- ATR 보정 라벨은 모델과 무관한 이름으로 바꿨다(`model-pred-minus-0.5-poolsd-atr14-z`, `model-return-reference-smooth`). 계산은 같다.

## 한계

- 비교 구간과 후보가 여러 연구에서 반복 사용되었다. 새 독립 OOS나 봉인 holdout 결과가 아니다.
- v7.1 대비 개선 폭은 신뢰구간이 0을 포함한다. 운영 첫 몇 주의 결과로 우열을 판단할 수 없다.
- 현재 상장 마스터·수정주가 기준으로 학습했다(생존 편향·수정주가 시점 차이 가능).
- Prepare가 KIS 투자자 매매동향 API에 새로 의존한다. 장애 시 추천을 중단하므로 백업 cron 재시도에 의존한다.
- Prepare 실행 시간이 약 2~3분 늘어난다(최근 실행 약 24분, 제한 38분).

## 재현 명령

```bash
# 1) 원천 수집 (KIS, 종목당 30거래일씩 과거로, 이어받기 지원)
npx tsx --env-file=.env.local scripts/stock-picks/export-investor-flow.ts collect \
  --symbols SYMBOLS.txt --from 20250115 --to 20261030 --output RAW.ndjson
# 2) 학습 행 export (운영과 같은 buildInvestorFlowInputs)
npx tsx scripts/stock-picks/export-investor-flow.ts export \
  --raw RAW.ndjson --calendar calendar.json --features features.ndjson --output investor-flow.ndjson
# 3) 학습 (기존 export 산출물 + 수급 입력)
uv run --script scripts/stock-picks/train-composite-utility.py --features features.ndjson \
  --feature-spec feature-spec.json --calendar calendar.json --prices prices.ndjson \
  --as-of 2026-10-30 --target demeaned-tp7-net-v1 --investor-flow investor-flow.ndjson \
  --output scripts/stock-picks/models/composite-return-v8.json --audit-dir AUDIT_DIR
```
