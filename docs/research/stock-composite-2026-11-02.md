# Stock Prepare: 2026-11-02 종합점수 v7.1 ATR 보정·점수 보정 복구

## 결론과 변경 범위

운영 정렬은 v7의 **당일 z(v6 예측값) − 0.5 × z(ATR14)** 순서를 유지한다(K2).
v7.1은 조정값을 v6 수익률 단위로 계산하고 기존 학습 기준 점수 곡선에 넣는다.
v6 단일 HGB 수익 회귀 모델과 기존 50개 관측 입력은 그대로 사용한다.
핵심 효과는 **−5% 이하 손실 감소**이며, 그 대가로 **+10% 장중 도달 비율도 낮아진다.**
타율·평균 순익은 비교 구간에서 높았지만, 평균 순익 차이의 블록 부트스트랩 검정은 유의하지 않았다.
**운영 성능 개선이 입증된 것은 아니다.**

UI, 이메일 템플릿, 제품 문구, Analysis Summary는 변경하지 않는다. 목표가·손절가는 표시하지 않는다.
기존 섀도우(`shadow:B-random`·`shadow:J-randomConstrained` 등)의 선정·점수도 변경하지 않는다.

## 데이터와 평가 계약

- 같은 275개 OOS 신호일(2025-09-03~2026-10-22)의 워크포워드 비교다. 10/19 문서의 265일 집계와 구간이 다르다.
- 정책별 자기 선정 이력으로 20거래일 재추천 제외(CD20), 하루 3종목을 선정한다.
- 진입은 다음 거래일 시가, 성과 판정은 D5 종가 기준이다. +10% 장중 도달(T10)은 별도 지표다.
- 평균 순익(EV)은 KRX 현실 비용(호가 단위 슬리피지 + 매도일 기준 거래세)을 차감한다. 고정 30bps가 아니다.
- L5는 D5 순익 −5% 이하 손실 비율이다. H2는 2026-04 이후 구간이다.
- 아래 결과는 같은 연구에서 여러 후보를 비교한 값이며 새 독립 OOS나 봉인 holdout 결과가 아니다.

## 같은 연구에서 기각한 접근

아래 후보는 모두 사전 등록한 채택 기준을 통과하지 못했다.

- 수익 부호 분류기(sign classifier), 중앙값 회귀(median regression), v6 + 분류기 혼합.
- 거래대금 하한(turnover floor).
- 문헌 기반 가격 피처 16개: MAX·왜도(skew)·야간/장중 수익·beta·IVOL·Amihud·52주 고점 관련 입력.
- LightGBM LambdaRank: 기존 50입력, 문헌 피처를 더한 66입력 양쪽.
- KIND 공시 피처/제외 규칙(24개 분류): G1 타율 45.2% / EV +0.69%, G2 veto 47.4% / +0.42%.
- 11/2 조합 M1(KIND 입력 + ATR 페널티): 타율 47.27% / EV +0.62%.
- 11/2 조합 M2(K2 + KIND veto): 타율 48.12% / EV +0.53%.

- 11/2 DART 재무제표(2023 연간~2026 반기, 시점 정합 14개 입력: 자본잠식·부채비율·분기 영업/순손실·매출 YoY·영업이익 전환·ROA·공시 경과일 등):
  D1(v6 + DART 입력) 45.21% / +0.38%, D2(재무 위험 veto) 학습 구간에서 기준을 만족한 플래그가 없어 v6와 동일,
  D3(K2 + veto) K2와 동일, D4(D1 + ATR 페널티) 46.79% / +0.22%.

일부 후보의 EV가 높더라도 사전 등록한 전체 기준을 통과한 것으로 보지 않는다.
11/2의 M1·M2는 타율·EV 모두 K2(48.36% / +0.65%)보다 낮았다.

## v7 점수 표시 사고(11/2)

2026-11-02 운영에서 v7이 100/100/99점을 표시했다. 순위용 당일 z 조정값에 임의의
`clamp(round(50 + 20 × adjusted), 0, 100)`을 적용해 상단 점수가 포화된 것이 원인이다.
이 변환은 학습 기준 평균 50·+1σ 70·완만한 상단 꼬리라는 v6 점수 의미를 유지하지 못했다.

v7.1은 `adjustedUtility = pred − 0.5 × poolStd(pred) × z(ATR14)`를 기존
`normalizeUtilityScore(FROZEN_COMPOSITE_RETURN_MODEL.normalization, adjustedUtility)`에 전달한다.
예측 표준편차가 양수이면 기존 조정값의 양의 선형 변환이므로 순위가 같고 위 백테스트 수치도 바뀌지 않는다.
예측 표준편차가 0인 풀은 보정 없이 `adjustedUtility = pred`를 사용한다.

## 운영 계산 계약

1. 기존 종합 점수 게이트(거래상태·유효 캔들·거래대금·RSI·우선주·신호일 수익·단일가 급락 제외)를 통과한 **20거래일 재추천 제외 전** 후보 풀을 만든다. 연구 export와 같은 풀이다.
2. 풀 전체에 기존 `scoreUtilityModel(...).utility`로 v6 연속 예측값을 계산하고 `feature.atrPercent14`를 읽는다.
3. 신호일별 풀에서 예측과 ATR 각각의 평균·모집단 표준편차를 계산한다. ATR z-score의 표준편차가 0이면 분모에 1을 사용한다. 예측 표준편차 `s`는 0을 그대로 보존한다.
4. `adjustedUtility = pred − 0.5 × s × zAtr`. `s == 0`이면 `adjustedUtility = pred`다. 통계를 고정한 다음 최근 20거래일 발행 종목을 제외한다.
5. 남은 후보를 연속 `adjustedUtility` 내림차순 → 기존 `averageTurnover20` 내림차순 → ASCII symbol 오름차순으로 정렬한다.
6. 표시 정수 점수는 기존 `normalizeUtilityScore(FROZEN_COMPOSITE_RETURN_MODEL.normalization, adjustedUtility)`로만 환산한다. 학습 기준 평균 50·+1σ 70·완만한 상단 꼬리를 유지한다. `utility`는 원시 v6 예측값이며 스냅샷 필드는 추가하지 않는다.

- 전략 버전: `v7.1-2026-11-02`.
- `parametersHash`는 기존 계약에 `rankAdjustment: 'v6-pred-minus-0.5-poolsd-atr14-z'`, `atrPenalty: 0.5`, `statsPool: 'gated-pre-cooldown'`, `scoreCurve: 'v6-return-reference-smooth'`를 포함한다.
- 모델 아티팩트는 `scripts/stock-picks/models/composite-return-v6.json` 그대로다. 재학습하지 않는다.
- v7.1의 ATR 조정값은 당일 후보 풀을 사용하며, 표시 곡선은 v6의 고정 학습 분포 기준을 사용한다. ATR이 당일 풀 평균이면 조정값과 점수는 원래 v6와 같다. 재추천 제외만 바뀌면 통계와 남은 후보 점수는 바뀌지 않는다.

## 남은 한계와 점검

EV 개선의 통계적 근거는 약하며 H2 EV는 여전히 음수다. 같은 OOS를 반복해서 본 선택 편향도 남는다.
5거래일 결과가 겹치므로 EV를 실제 자금 운용 수익률로 해석하지 않는다.
운영에서는 기존 무작위 섀도우와 함께 D5 타율·EV·T10·L5를 비교하고, 손실 감소와 상승 도달 감소를 함께 확인한다.
