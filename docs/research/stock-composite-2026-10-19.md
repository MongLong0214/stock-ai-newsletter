# Stock Prepare: 2026-10-19 종합점수 v6 교체

## 결론과 PR 범위

운영 종합점수를 v5(`clip(touch) × clip(nonLoss)²`)에서 v6 단일 HGB 수익 회귀로 교체한다.
v6 목표는 **같은 신호일 후보 평균을 뺀, 비용 차감 후 D5 수익(+7% 도달 시 +7%로 상한)**이다.
입력은 기존 50개 관측 피처 그대로이며 후보 풀·공통 게이트·급락 제외·20거래일 재추천 제외·
정수점수 → 20일 평균 거래대금 → ASCII ticker 정렬은 바꾸지 않는다.
v5는 백테스트에서 무작위보다 타율이 낮아 섀도우로 남기지 않는다. 운영 비교 기준은 기존 `shadow:B-random`·`shadow:J-randomConstrained`다.

워크포워드 비교에서 v6는 v5 재현 정책보다 D5 타율과 평균 순익이 높았고, +10% 장중 도달 비율은 저변동 정렬처럼 무너지지 않았다.
**운영 성능 검증 완료는 아니다.** 독립 리뷰(gpt-6.1-sol)는 "shadow 수집 GO, 운영 교체 NO-GO"였고,
Isaac은 이 반대 의견을 확인한 뒤 운영에서 바로 확인하며 개선하는 쪽이 효율적이라고 판단해
v6 단독 즉시 교체를 결정했다(2026-10-19).
UI, 이메일 템플릿, 제품 문구, Analysis Summary는 변경하지 않는다. 약관상 목표가·손절가는 표시하지 않으므로 TP 청산은 제품 지표가 아니며, 판정은 D5 종가 기준이다.

## 데이터와 평가 계약

- 연구 corpus: 2026-10-16 시점 KIS 확정 일봉 스냅샷과 현재 master로 실제 TS 피처·게이트·라벨 코드를 호출한 export(신호일 395일, 2025-03-04~).
- 워크포워드: 확장 창, 21거래일마다 재학습, 학습 마지막 신호와 평가 시작 사이 6거래일 embargo(D5 라벨 성숙 확인).
  평가 신호일 265일(2025-09-03~2026-10-07).
- 선정: 정책별 자기 선정 이력으로 20거래일 재추천 제외, 하루 3종목. 진입 = 다음 거래일 시가, 청산 = D5 종가.
- 비용: `trading_cost.py`의 KRX 현실 비용(호가 단위 슬리피지 + 매도일 기준 거래세). 고정 30bps가 아니다.
- 성숙했지만 라벨이 없는 선정(정지·데이터 오류)은 −30%로 채운다(−100% 민감도 병기).
- 학습: 날짜 동일 가중, early stopping 없음, HGB 200트리 / leaves31 / min_samples_leaf 500 / L2 1 / lr .05.
- 비교군 "v5 재현"은 동일 corpus·동일 경계로 touch·nonLoss 두 헤드를 재학습한 것이다. 당시 실제 발행 종목 성과가 아니다.
- **같은 날짜를 보며 여러 목표·입력·모델 크기를 탐색했다.** 아래 p값은 다중 비교 보정 전이며 새 독립 OOS/봉인 holdout이 아니다.

## 남은 한계와 반대 의견

- 현재 master의 활성 여부를 과거 전체에 적용했다(비활성 218종목 제외). 생존 편향이 남는다.
- 008040·207760은 2026-04-02 전후 가격 단위 불연속이 있다. 원인 미확정.
- 연구는 매일 추천한다. 실제 Prepare의 `CRASH_ALERT` 우회일은 시뮬레이션하지 않았다.
- 5일 결과가 겹치므로 실제 자금 운용 수익률이 아니며, 반 호가 슬리피지 가정이 고ATR 종목의 실제 체결을 보장하지 않는다.
- sol 리뷰는 수정된 단일 정책을 동결하고 실제 Prepare 시점 shadow로 최소 60 성숙 신호일을 본 뒤 교체를 다시 논의하라고 권고했다.
  이번 교체는 그 권고와 다르며, 운영 성과를 무작위 섀도우와 비교하며 개선한다.

## 운영 모델

- `scripts/stock-picks/models/composite-return-v6.json` (schema 5, 200트리, sha256 `4ca86e21…5c12fb3`).
- 2026-10-16 KIS 확정 스냅샷 재학습: 학습 마지막 신호 2026-10-08 → 성숙 2026-10-16, 391패널 / 474,242행.
- 점수 환산: 학습 예측의 날짜 동일 가중 평균(≈0)·표준편차(0.00679)를 기준으로 평균 50·+1σ 70의 기존 곡선을 쓰되, 예측값을 [0,1]로 자르지 않는다(`return-reference-smooth-v1`).
- +7% 도달은 기존 +10% 판정과 같은 정수 비교(`floor(고가+.5)*100 >= floor(진입가+.5)*107`)다. 실수 비교 대비 학습 라벨 6행이 바뀌었다.
- Python 원본 모델과 TS 추론기의 예측·정수점수 대조 20,097건 차이 0건.
- 읽기 전용 재현(10/16 신호, 실제 발행 이력의 20일 제외 목록): 기존 v5 코드는 실제 10/19 발행 3종목(제너셈·헬릭스미스·피에스케이홀딩스)을 순서까지 재현했고,
  v6는 로킷헬스케어(89점)·아이에스티이(87점)·SK스퀘어(85점)를 골랐다. 발송 또는 수익 확정 기록이 아니다.
- 위 라벨 6행 수정 전 학습본은 같은 날 제이에스링크·로킷헬스케어·와이지-원을 골랐다. 상위 점수가 촘촘해 재학습 때마다 개별 종목은 바뀔 수 있으며,
  연구 비교는 특정 학습본이 아니라 같은 학습 방식의 워크포워드 성과다.
