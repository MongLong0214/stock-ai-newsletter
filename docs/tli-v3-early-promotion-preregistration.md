## 1. 결정

PRD §8의 "4주 shadow 후 승격"을 최초 승격에 한해 **progressive delivery**로 대체한다:

```
PIT 리플레이 감사 (오늘) → 통과 시 당일 champion 승격 + 실험(beta) 라벨 노출
→ 라이브 트립와이어 상시 감시 → D+14 확인 체크포인트 (통과=확정 / 미달=자동 롤백)
```

## 2. 근거 (왜 이것이 무모하지 않은가)

1. **현직 champion(b-abl-v1) 자체가 prospective 검증된 적 없는 휴리스틱**이며, offline 실측에서 ECE 0.2437(심각한 미보정), IC -0.0571(GT-A 역방향 예측)로 나타났다. 4주 gate의 보수성은 "검증된 champion을 근소한 challenger로부터 보호"하기 위한 설계인데, 지금은 그 전제가 성립하지 않는다.
2. **효과 크기가 gate 설계 범위 밖으로 크다**: 상대 개선 22.3% (gate 최소 기준 2%의 11배), 99% CI [-0.0741, -0.0353]로 0에서 결정적으로 이탈, 비중복 n=1,751 (최소 기준의 7배).
3. **되돌리기가 싸다**: 롤백 RPC(038) + 노출 플래그(`TLI_PREDICTIONS_V3_EXPOSURE_ENABLED`) 이중 안전망. 실패 시 피해 반경 = UI 확률 배지 1개 (점수 정렬은 Q6 결정대로 유지되므로 불변).
4. **남은 유일한 실질 리스크 = offline→serving 전이 버그** (누수, 아티팩트 직렬화, 서빙 경로 불일치). 이것이 리플레이 감사가 정확히 겨냥하는 대상이다.

## 6. D+14 확인 체크포인트 (2026-07-21)

- 라이브 예측(7/8~7/21) vs 동일 행 B-abl shadow, theme-cluster bootstrap 99% Brier delta CI.
- **통과** (upper < 0): 승격 확정. 기록용으로 4주 시점 표준 gate 리포트도 생성.
- **미달** (upper ≥ 0): 자동 롤백 + 포스트모템. 이후 표준 4주 gate 경로만 사용.
