# TLI v3 M1 승격 강화 프로그램 — 2주 내 승격 확률 극대화

Owner: CTO (Fable). Date: 2026-07-07. Target: 2주 내(≈2026-07-21) M1이 **동결된** promotion gate를 정직하게 통과할 확률을 ≥87%로 끌어올린다.

## 0. 무결성 경계 (먼저 못박음 — 이 문서의 존재 이유)

"승격 확률 87%"는 **게이트를 진짜로 통과할 확률**을 높이는 목표다. 다음은 절대 하지 않는다:
- 임계값(ECE≤0.08, Brier 2%, P@10 5pp) 이동/완화 — 동결.
- 평가 데이터에 보정기를 맞춰 ECE를 낮추기(circular) — 보정기는 **train fold에 적합, held-out test/shadow에서 측정**.
- 결과를 본 뒤 방법론 변경 — 모든 방법론은 재평가 **전에** 커밋(순서가 증거).
- 유리한 단일 윈도우 cherry-pick — 다중 윈도우 전부 통과를 요구.

**만약 모든 합법적 레버 소진 후 정직한 확률이 87% 미만이면, 그 숫자를 그대로 보고한다.** 87%는 엔지니어링 프로그램의 북극성이지, 수단 방법 안 가리고 맞출 숫자가 아니다. 이걸 어기면 v2가 무너진 그 길이다.

## 1. 결정적 진단 — 병목은 ECE 단 하나

동결된 gate 5개 조건 중 M1의 현재 상태(리플레이 2차, 방법론 정정 후):

| 조건 | 실측 | 판정 | 성격 |
|---|---|---|---|
| Brier point + 2% + 99% CI upper≤0 | upper −0.0093, 상대 18% | **PASS** | 견고 |
| **ECE ≤ 0.08** | **0.0804** | **FAIL** | **유일 병목, 0.0004 초과** |
| ECE upper95 ≤ 0.12 | (미측정, point 근처) | 경계 | — |
| P@10 drop ≤ 5pp | +10.7pp | PASS | 견고 |
| n_eff ≥ 250 | 리플레이 285 weekly / shadow 축적중 | 경로별 | — |

**핵심 통찰**: 승격을 막는 건 ECE 하나다. 그리고 ECE는 **보정(calibration) 지표** — 모델의 판별력(IC)과 독립적으로, 재보정만으로 직접 개선 가능한 유일한 gate 지표다. Brier·P@10은 이미 마진 두고 통과. 즉 **문제가 가장 다루기 쉬운 곳에 정확히 몰려 있다.**

## 2. 레버 분석 (효과 크기 · 확실성 · 타임라인)

### L1 — 보정기 업그레이드 (Platt → Beta/Isotonic, CV 선택) 【최고 레버】
- 현재 Platt(sigmoid, 1-param)은 비-sigmoid 형태의 미보정을 못 잡는다. **Beta calibration**(Kull 2017, 3-param, Platt를 특수케이스로 포함, smooth)과 **Isotonic**(단조 비모수)을 추가하고, **중첩 CV의 held-out ECE로 자동 선택**.
- 왜 거의 확실한 개선인가: (a) ECE는 isotonic이 직접 최소화하는 대상 (b) **isotonic·beta는 rank-preserving → IC·P@10 불변, Brier는 개선/유지** — gate에 거의 순수 이득 (c) 미달폭이 0.0004로 극소.
- 리스크: 작은 calibration set에서 isotonic 과적합 → beta가 더 안전한 기본. CV 선택이 과적합 자동 차단.
- 타임라인: **1~2일** (train_m1.py + 아티팩트 스키마 + TS predict + 골든벡터).
- 예상: replay ECE 0.0804 → **<0.06 (높은 확률)**.

### L2 — 죽은 피처 부활 (앵커 버그 파급) 【판별력 레버, 느림】
- 오늘 발견: `anchor_scaled_value`가 배포 이래 영구 null → `interest_level_pct`(교차 앵커 평균 의존) 피처가 **줄곧 죽어 있었음**(항상 imputed). 앵커 수정으로 부활하나, 데이터가 쌓여야(2~3주) 리플레이/shadow 윈도우를 덮는다.
- **추가 감사 필수**: 앵커처럼 조용히 죽은 다른 피처가 있는가? 10개 피처의 missing-flag 비율·분산을 실측. 2~3개가 죽어 있으면 IC 억제의 주범 → 부활 시 판별력 상승.
- 타임라인: 감사 즉시(오늘), 앵커 데이터 축적은 2~3주(2주 창 경계).
- 성격: IC를 올리나 **gate 조건 아님** → 승격을 막지도 않고 보장하지도 않음. "승격 후 가치"를 좌우.

### L3 — 다중 윈도우 일관성 (P(shadow 확인)을 올리는 정공법) 【확률 강화 레버】
- 단일 2주 전향 창에 운을 거는 대신, 재보정 모델을 **최근 롤링 윈도우 3~4개**로 리플레이(예: train≤5/15 test 5/25–6/12, train≤5/29 test 6/8–6/26, train≤6/12 test 6/22–7/6)하고 **전부 통과를 요구**. 독립 최근 창들을 모두 통과하면 "다음 2주에도 유지"의 사후확률이 급등 — 대기 없이 신뢰를 산다.
- 타임라인: 2~3일 (재보정 완료 후 배치 실행).

### L4 — 전향 shadow 청결화 (D+14 확인을 신뢰 가능하게)
- 1,000행 캡·앵커 수정으로 서빙 경로 정상화 확인, p_rise non-null 커버리지 일일 모니터링, ECE/Brier 궤적 일일 추적(엔드포인트가 아니라 추세로 조기 경보).

## 3. 정직한 확률 모델

P(2주 내 승격) = P(재보정 후 다중윈도우 리플레이 통과) × P(D+14 shadow 확인 | 리플레이 통과) × P(신규 블로커 없음)

**착수 시점 정직한 추정 (레버 적용 전):**
- P(리플레이 통과): ECE만 병목, 재보정이 직격 → 0.85~0.92
- P(shadow 확인): 진짜 out-of-sample 불확실성, 반사성/분포shift → 0.80~0.90
- P(블로커 없음): 계속 버그 발견 중 → 0.90
- 곱 ≈ **0.61~0.74**

**레버 적용 후 목표:**
- L1(robust 재보정, 3방법 CV) → P(리플레이 통과) 0.93
- L3(다중윈도우 전부 통과) → P(shadow 확인) 0.90 (독립 창 일관성이 근거)
- L2 감사(죽은 피처 선제 제거) → P(블로커 없음) 0.93
- 곱 ≈ **0.78**

**냉정한 결론**: 착수 시 ~65%, 레버 총동원 후 ~78%가 정직한 상한 근처다. **87%까지의 마지막 갭은 "2주 후 실제 세계에서 유지되는가"라는 환원 불가능한 불확실성** — 어떤 엔지니어링도 미래 2주를 완전히 없앨 수 없다. 다중윈도우 일관성이 이걸 최대한 좁히는 정공법이고, 그 실측 결과에 따라 87% 도달 여부가 갈린다. **진단이 "ECE가 sample-limited(대기가 유효)"로 나오고 다중윈도우가 전부 통과하면 87%는 현실적. 구조적이거나 창별로 들쭉날쭉하면 정직하게 그 이하를 보고한다.**

## 5. 사전 등록 갱신 (게이밍 차단)

- 본 프로그램의 방법론 변경(보정기 업그레이드, 다중윈도우 요구, 피처 수정)은 **결과 측정 전에 커밋**한다. 커밋 해시 순서가 무결성 증거.
- 조기 승격 기준 C1~C4는 유지. 추가: **C5 = 다중윈도우(≥3) 전부 C1~C4 통과.** D+14 shadow 확인은 별도 최종 관문.
- 반복 look(주간 재시도)의 α 소진을 `early-promotion-preregistration.md`에 누적 기록.

## 5.5 실측 결과 (2026-07-08 확정 — 프로그램 종결 판정)

레버 전부 실행 후 실측:
- **L1 재보정**: random-fold CV가 isotonic 과적합을 선택(OOS 0.1041로 악화) → temporal forward-chaining CV로 교정, platt 유지. **재보정으로 ECE를 낮추는 레버는 사실상 소진** (in-sample은 어떤 보정기든 ~0.015, 문제는 OOS 이동).
- **L2 피처 감사**: 10개 중 2개(interest_level_pct, episode_progress)가 완전 사망 상태 발견. 앵커 수집 개시(7/7)·에피소드 peak 보존 수정으로 **전향적으로만** 부활 — 2주 창 밖.
- **L3 다중윈도우**: 3창 중 **1창만 전부 통과** (A pass / B IC 붕괴 / C ECE 0.0011 초과). Brier 우위만 3/3 복제.
- **정직한 최종 확률**: 조기 경로(2주 내) **~30-40%** — 87% 목표 미달 확정. 표준 gate 4주 정각 ~40-50% (ECE point 경계 + upper95@n250 리스크), 8주 연장 포함 ~60-70%.
- **북극성 관점의 진짜 결론**: "champion보다 잘 보정된 확률"은 3/3 복제된 실가치. 랭킹 실력(IC)은 레짐 의존적으로 명멸 — 이를 안정화할 레버는 gate 엔지니어링이 아니라 **피처**(앵커 부활, 에피소드 부활, 신규 피처)다. 게이트 통과는 그 결과로 따라온다.

## 6. CTO 책임 선언

이 프로그램은 승격을 "만드는" 게 아니라, M1이 승격될 자격이 있으면 그것이 드러나도록 **모든 정직한 장애물을 제거**하는 것이다. 2주 후 숫자가 87%든 72%든, 측정된 값을 그대로 보고하고 근거를 제시한다. 승격이 정당하면 밀어붙이고, 아니면 막는다 — 둘 다 CTO의 일이다.
