# TLI 최종 지향점 — 제품 비전과 실행 로드맵

Status: Isaac 승인 (2026-07-08, "목표하는 지향점에 도달할 수 있게 모든 수를 총동원" 위임)
Owner: CTO. 이 문서가 TLI 투자 판단의 canonical 기준.

## 0. 한 문장 정의

**TLI는 주가가 아니라 "관심(attention)의 미래"를 예측한다** — 한국 테마 시장에서 관심이 곧 게임이며, 관심 예측의 수익화는 주가 예측을 요구하지 않는다.

실측 근거: M1의 관심 상승 예측은 3/3 리플레이 창에서 champion 대비 Brier 우위(99% CI). 엣지는 얇지만(climatology 대비 ~7-12%) 실재하고 잘 보정됨. 관심→주가 다리(GT-B)는 문헌·사전확률 모두 회의적 → **영원히 검증 전용, 증명 전 판매 금지.**

## 1. 최종 모습 — 3층 구조

### 1층: 정직한 측정 엔진 (거의 완성)
외부 GT(검색량), PIT 규율, 보정된 확률, 자기교정 학습 루프. 해자 = 세상의 테마 트래커는 대부분 vibes인데 이것은 자기 성적표를 외부 기준으로 매긴다. 부산물 = 라벨링된 한국 테마 생명주기 수년치 데이터 자산(복제 불가).

### 2층: 사용자 제품 — "테마 조기 경보"
241개 점수판(소음)을 대체하는 매일 아침의 신호:
> 이번 주 주목받을 확률이 높은 테마 3~5개 — 보정된 확률, 근거(검색 가속/뉴스/수급), 식어가는 테마 경고

- 얇은 IC로도 성립 (큐레이션은 랭킹 상위만 사용, P@10이 champion의 1.6~2배)
- 보정된 확률이라 과장 없이 말할 수 있음 — "투자 권유 아님" 원칙 유지
- 전제조건: M1(계열) champion 승격 + 노출. UI 신설은 Isaac 사전 승인 필수 (대원칙 #3)

### 3층: 내부 플라이휠 — 자기 소비 (가장 빠른 가치)
**예측의 첫 고객은 자사 콘텐츠 엔진.** "다음 주 X 테마 상승 확률 65%"를 알면 X 심층 콘텐츠를 정점 전에 발행해 검색 수요를 선점한다. IC 0.12로도 성립 (행동 비용 ~0, 보상 비대칭). 반사성은 여기선 리스크가 아니라 레버리지 (라벨 오염 감시는 유지 — reflexivity report).
- **승격·노출·UI 없이 shadow 예측만으로 오늘부터 가동 가능** — 무후회 트랙.

## 2. 실행 페이즈

| Phase | 내용 | 전제 | 상태 |
|---|---|---|---|
| A. 모델 강화 | m1.1 (analog 피처 13개) → 3창 재판정 → 통과 시 사전등록 조기경로 재개 | — | 진행 중 |
| B. 플라이휠 MVP | 일일 테마 워치리스트 리포트 (shadow 기반, 내부용) → 콘텐츠 우선순위에 활용 | 없음 (무후회) | 착수 |
| C. 피처 부활 관측 | 앵커(~7/16 계산 가능), 에피소드(전향 축적) → 주간 재학습에 자연 반영 | 시간 | 자동 |
| D. 승격 | 조기경로(3창 전부 통과) 또는 표준 gate (4~8주) | A/C 결과 | 대기 |
| E. 조기 경보 UI | 2층 제품화 (확률 배지 + 워치리스트 섹션) | D + Isaac UI 승인 | 대기 |
| F. GT-B 리서치 | 관심→바스켓 수익 전이 검증 (판매 금지, 리서치 전용) | D 이후 | 백로그 |

## 3. 킬 크리테리아 (정직성 장치)

**피처 부활 + m1.1 이후에도** ① 관심 예측 IC가 안정적으로 0.1을 못 지키고 ② 워치리스트 기반 콘텐츠가 트래픽 리프트를 못 보이면 → 유지보수 모드 동결, 투자 중단. 단 판정은 공정 측정 개시(2026-07-07, 서빙 정상화) 이후 충분한 관측 뒤에만.

## 4. 불변 원칙

1. 게이트·기준은 측정 전에 커밋 (사전 등록) — 결과 보고 기준을 바꾸지 않는다.
2. 주가 예측력은 증명 전 절대 팔지 않는다 (GT-B는 검증 전용).
3. 노출 시 "실험" 라벨 + 트립와이어 + 자동 롤백.
4. UI 신설은 Isaac 사전 승인 (대원칙 #3).
