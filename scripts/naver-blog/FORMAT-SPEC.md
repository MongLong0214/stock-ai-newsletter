# 네이버 블로그(inside 트랙) 발행 포맷 규격

**작성 근거**: (1) 네이버 공식 C-Rank·D.I.A.+ 문서(help.naver.com, blog.naver.com/naver_search),
(2) 2025년 최신 스마트블록 최적화 가이드 3건 교차검증, (3) "관련주·테마주·종목분석·주식추천"
4개 키워드로 실제 네이버 VIEW 상위노출된 재테크 블로그 글 28개 직접 열람·구조 분석(2026-08-27).
샘플 규모는 "500개"에는 못 미치지만, 공식 알고리즘 문서 + 최신 2차 자료 + 실제 상위노출 글 샘플을
교차검증했다는 점에서 근거 등급은 충분하다.

## 0. 왜 지금 포맷을 바꾸는가

첫 테스트 발행글(`면세점 테마, 이번 주 점수 68점으로 상승`)은 아래 표의 **"필수 요소"를 전부 놓쳤다.**

| 항목 | 실제 상위노출 28개 글 기준 | 테스트 발행글 |
|---|---|---|
| 이미지 | 28/28 (100%) 최소 1장, 평균 5.1장 | **0장** |
| 소제목(인용구 박스) | 20/28 (71%), 평균 3~5개 | **0개** |
| 색상/볼드 강조 | 20/28 (71%) 색상, 평균 볼드 16.4회 | **0회** |
| 본문 글자 수 | 평균 3,021자 (범위 1,089~6,547) | **약 500자** |
| 태그 수 | 평균 7.7개 | 3개 |
| 마무리 | 요약/CTA/투자비권유 고지/출처 중 최소 1개 | 링크만 덜렁 |
| 도입부 후킹 | 질문형·자기소개·핵심수치 중 하나로 시작 | 데이터 나열로 바로 시작 |

이미지 0장은 특히 치명적이다 — 샘플 28개 중 이미지가 없는 글은 **단 하나도 없었다.** D.I.A.+ 로직도
이미지 유무를 문서 품질 신호로 명시한다(QnA: "이미지는 꼭 1개 이상 넣어주셔야 합니다").

## 1. 제목 공식

- **길이**: 25~45자 (25자는 구버전 가이드 기준, 최신 실측 평균은 36.9자 — 너무 짧으면 정보 부족, 너무 길면 잘림)
- **키워드 위치**: 목표 키워드(테마명/종목명)를 제목 맨 앞에 배치
- **숫자 포함**: 점수·개수·연월 중 최소 1개 필수 (28개 중 50%가 숫자 포함)
- **형태는 아래 3개 중 택1** (자동화 파이프라인은 A 고정 권장 — 재현성 때문):

  ```
  A) [테마명] 관련주 TOP N — [단계] 진입, 점수 NN점 (YYYY.MM)
     예: "면세점 관련주 TOP 6 — 정점 단계 진입, 점수 68점 (2026.08)"

  B) [테마명] 점수 NN점 [상승/하락] — [핵심 변화 한 줄]
     예: "면세점 테마 68점 상승 — 뉴스는 줄고 검색은 늘었다"

  C) [테마명] 관련주, [핵심 질문]?
     예: "면세점 관련주, 지금 정점일까 신호일까?"
  ```

- **금지**: 낚시성 확률·수익 단정("확률 87%", "500만원 벌었다"), 과도한 느낌표, "AI가 분석한" 같은 AI 강조 문구
  (자사 사이트 SEO 가이드라인과 동일한 이유 — YMYL 신뢰도 훼손)

## 2. 본문 구조 (고정 템플릿 — 5개 블록)

자동 생성 파이프라인은 아래 5블록을 **항상 이 순서로** 채운다. 순서를 고정하는 이유는 "찍어낼 수
있는 규격"을 만들기 위함 — 매번 새로 구조를 고민하지 않는다.

```
[블록 1] 후킹 도입부 (100~200자, 이미지 1장 필수)
  - 제목의 핵심 키워드를 첫 문장에 그대로 반복 (SEO 필수 — D.I.A.+ 문서 재확인)
  - 질문형 또는 핵심 수치 제시로 시작
  - 예: "면세점 관련주 8개를 묶은 테마 점수가 이번 주 68점을 기록하며 정점 단계에 들어섰습니다."

[블록 2] 인용구 박스 소제목 "점수 현황" (200~400자, 이미지 1장)
  - 점수·단계·기준일 + 전주 대비 변화
  - 핵심 수치는 볼드 처리, 상승/하락 방향에 따라 빨간색(#ff0010)/파란색(#0068ff) 강조.
    색상은 스마트에디터 툴바로 실제 적용하고 DOM에서 검증한다. 실패하면 볼드로 강등하지 않고 발행을 중단한다.

[블록 3] 인용구 박스 소제목 "점수를 만든 네 가지 요소" (300~500자, 이미지 1~2장)
  - 4개 구성요소(검색관심도/뉴스모멘텀/활동성/변동성) 수치 서술
  - 뉴스 건수 전주 대비, 검색 관심도 7일/30일 평균 비교
  - 이 부분이 스탁매트릭스의 실제 차별화 데이터 — 경쟁 블로그가 못 베끼는 부분이므로 가장 공들여 쓴다

[블록 4] 인용구 박스 소제목 "관련종목" (200~400자, 이미지 1장 — 가능하면 종목 표)
  - 관련 종목 리스트 (①②③ 번호 또는 표)
  - 종목명은 볼드 처리

[블록 5] 마무리 (150~250자, 이미지 불필요)
  - 요약 한 줄
  - 투자비권유 고지 (YMYL 필수 — 아래 4번 항목 그대로 사용)
  - 출처·기준일 명시 ("사실 확인에 활용한 데이터: 네이버 데이터랩, KRX 시세, 기준일 YYYY.MM.DD")
  - StockMatrix 링크 CTA (outsideUrl, 오글링크 카드로 자동 변환되는 문단 끝 URL 형태 유지)
```

**총 분량 목표: 1,500~2,500자, 권장 1,800~2,200자.** 2,500자를 넘기면 다음 소제목으로 쪼갠다.
인용구는 글 전체 3~5개(권장 4: 점수 현황 / 점수를 만든 네 가지 요소 / 관련종목 N개 / 정리).
생명주기·데이터 갱신 설명은 인용구가 아니라 일반 문단(볼드 리드)으로 둔다.

## 3. 서식 규칙

- **문단 길이**: 한 덩어리(네이버 에디터 컴포넌트 기준) 100~400자. 3문장 넘으면 무조건 끊는다.
- **소제목**: 일반 텍스트가 아니라 **인용구(따옴표) 블록**으로 넣는다 — 28개 중 71%가 이 방식을
  써서 시각적으로 소제목처럼 보이게 한다. 스마트에디터 단축키: `/인용구` 또는 툴바의 " 아이콘.
- **강조**:
  - 핵심 수치(점수, %, 종목명)는 **볼드** 처리
  - 상승/호재 수치는 빨간색(`#ff0010` 계열), 하락/주의 수치는 파란색(`#0068ff` 계열)
  - 글 전체 볼드 사용 횟수 목표: 10~20회 (실측 평균 16.4회)
- **리스트**: HTML 리스트보다 `①②③` 번호나 `→` 화살표로 텍스트 나열하는 게 네이버 관행과 더 맞음
- **이모지**: 원칙적으로 미사용. 재테크/증권 카테고리는 이모지 사용률 14%뿐이고, 신뢰도를 우선하는
  업계 관행이 뚜렷함. 예외 허용 안 함 (팁박스 등 캐주얼 연출은 지금 단계에서 하지 않는다).
- **어조**: 존댓말(합니다체) 고정. 반말 절대 금지 — 샘플 28개 중 반말 사용 0건.

## 4. 이미지 규칙

- **최소 4장, 목표 5~7장** (실측 평균 5.1장, "AI 브리핑형" 데이터 저널리즘 포스트 그룹은 평균 9장)
- **배치 간격**: 300~400자마다 1장 (문단 사이)
- **소스**: stockmatrix.co.kr의 실제 차트/스크린샷을 사용한다 (`/themes/{id}` 페이지의 점수 게이지,
  구성요소 바 차트, 관련종목 카드 등을 스크린샷 캡처). 외부 이미지 재사용 금지 — 네이버가 출처
  판별 가능하고 D.I.A.+ 점수에 감점 요인.
- **캡처 자동화**: `npm run naver:capture -- <themeId>` (`scripts/naver-blog/capture-images.ts`).
  글 유형별로 타깃이 다르다. theme 글은 히어로·관련종목(필요 시 4개씩 분할)·점수 추이(데이터 선이
  있을 때만)·관련뉴스. **일반 theme 글에서 유사패턴·테마전망은 기본 제외**한다(전망·해석 문구와
  YMYL 충돌). similar 글만 유사패턴을 쓰고, 본문에 그 의미를 설명한다.
- **캡처 영역 계산**: CSS 클래스가 아니라 **화면에 보이는 한국어 소제목**으로 섹션을 찾는다.
  h1/h2만 경계로 쓰고(h3는 카드 내부 제목이라 섹션이 80px로 잘린다), 열 폭은 소제목 rect가
  아니라 이를 감싸는 레이아웃 블록에서 잰다. 캡처는 항상 스크롤 최상단으로 되돌린 뒤 문서
  절대좌표로 찍는다 — 스크롤된 상태의 clip은 지연 렌더로 좌표가 밀린다.
- **빈 캡처 차단**: 점수 게이지가 렌더되지 않으면 필수 대상은 throw한다. PNG 15KB 미만은
  빈 영역이다. **해당 섹션 안의** Recharts path가 실제 곡선인지, `비교선이 아직 없어요`가
  없는지 검사한다. 페이지 전체의 다른 SVG로 통과시키지 않는다. 관련종목은 API 종목 수와
  화면에 보이는 행 수가 같아야 하고, 한 장에 안 들어가면 4개씩 두 장으로 나눈다.
- **배치**: 이미지 위치는 문단 인덱스가 아니라 본문의 `{{image:id}}` 슬롯(의미 블록)이다.
  배치되지 않은 이미지를 글 끝에 붙이지 않는다. CTA(오글링크)가 마지막 컴포넌트이며 CTA 뒤
  이미지·문단은 발행 중단 사유다. 연속 이미지 금지. 각 이미지 뒤에 캡션 한 줄(점수·변화·기준일).
- **초안·이미지 원자화**: 공용 `.naver-blog/images`를 쓰지 않는다. 각 초안은
  `.naver-blog/runs/{UTC}-{themeId}-{rand}/` 아래 `draft.json`·`images/`·`manifest.json`을
  임시 디렉터리에 만든 뒤 rename한다. 본문·캡션·manifest는 상세 API `score.change7d`를
  단일 소스로 쓴다. 랭킹 값과 다르면 상세를 택하고 경고한다. 발행 전 SHA-256과 상세 API를
  다시 대조하고, 불일치 시 초안 재생성을 요구한다.

## 8. 발행 전 체크리스트

```
[ ] 제목 25~45자, 키워드 맨 앞, 숫자 1개 이상 포함
[ ] 첫 문장에 제목의 목표 키워드(예: "면세점 관련주") 정확 일치
[ ] 본문 1,500~2,500자 (권장 1,800~2,200)
[ ] 유효 이미지 4~7장, 캡션 있음, CTA 뒤 0장, 연속 배치 없음
[ ] 인용구 박스(소제목) 3~5개, 각 인용구는 제목 한 줄만
[ ] 실제 볼드 10~20회, 색상 마커는 DOM 빨강/파랑으로 적용
[ ] 태그 8~12개 — 초안과 실제 입력이 같고 잘라내지 않음
[ ] 마무리에 투자비권유 고지 문구 포함
[ ] 마무리에 outsideUrl(스탁매트릭스 링크) 포함, 방법론 링크는 본문 문장 안에
[ ] 반말/이모지/느낌표 과다 없음
[ ] 카테고리 = StockMatrix로 명시 선택 (마지막 사용값에 의존하지 않음)
[ ] 블로그 ID = stock-matrix (NAVER_BLOG_ID 우선). 세션 계정이 다르면 npm run naver:login 재실행
```

## 9. Before / After 예시 (동일한 실데이터 기준)

### Before (테스트 발행글 — 이 스펙 적용 전)

```

'정점' 구간입니다. 기준일은 2026년 8월 26일입니다.
점수를 구성하는 네 요소를 뜯어보면 이렇습니다. 네이버 검색 관심도가 0.89로 가장 높고, 뉴스
모멘텀 0.76, 활동성 0.67, 변동성 0.30 순입니다. ...
(이하 데이터 나열, 이미지 0장, 소제목 0개, 강조 0회, 총 약 500자)
```

## 10. 글 유형 로테이션 (매일 1편)

발행 유형을 5종으로 나눈다. 한 종류만 계속 내면 테마명과 숫자만 바뀐 글이 쌓이고,
그것이 네이버 저품질의 대표 신호("동일 문구 대량 반복")다.

| 회차 | 유형 | 데이터 소스 |
|---|---|---|
| 1 | theme | `/api/tli/themes/{id}` — 개별 테마 심층 |
| 2 | ranking | `/api/tli/scores/ranking` — 단계별 상위 집계 |
| 3 | theme | (다른 테마) |
| 4 | similar | `theme.comparisons` — 과거 사이클 대조 |
| 5 | theme | (다른 테마) |
| 6 | news | `theme.recentNews` — 날짜·매체가 매번 달라진다 |
| 7 | evergreen | 지표 설명 7주제 로테이션 (`compose-evergreen.ts`) |

- 유형은 **KST 날짜**에서 뽑는다(`typeForDate`). 발행 기록 수로 세면 GitHub Actions 러너가
  매 실행 새 VM이라 회차가 늘 0이 되고, 로테이션이 통째로 죽는다.
- 같은 테마는 **14일 쿨다운**(`THEME_COOLDOWN_DAYS`). 발행이 **성공한 뒤에만** 기록한다.
- evergreen 주제가 7종이라 같은 문장이 돌아오는 간격은 7 × 7 = 49일이다.
- 데이터가 모자라 news·similar를 못 쓰면 theme이 아니라 **ranking**으로 떨어진다
  (theme은 이미 3/7이라 폴백까지 theme으로 보내면 같은 템플릿이 몰린다).
- 발행 이력·쿨다운은 `.naver-blog/state/`에 쌓고 CI에서는 `actions/cache`로 실행 간에 넘긴다.
  세션 쿠키(`session.json`)는 이 디렉토리 밖이라 캐시에 올라가지 않는다.

발행 대상 블로그는 `https://blog.naver.com/stock-matrix` (ID `stock-matrix`, 하이픈 포함).
환경변수 `NAVER_BLOG_ID`가 있으면 그것을 우선한다. 세션이 다른 계정이면 로그인 자동화 없이
`npm run naver:login` 재실행을 요구하고 멈춘다.

주간 발행 상한은 `session.ts`의 `WEEKLY_PUBLISH_LIMIT`(기본 7, 매일 1편). 이 값을 완화하지 않는다.
